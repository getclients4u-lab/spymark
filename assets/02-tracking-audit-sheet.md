# The Tracking Audit Sheet™ + Origin Log™

**Deliverable 2 · SpyMark Protection System™**

Print this, or copy it into a note. Fill it in as you audit. By the time you're done you will have — for the first time ever — a complete picture of what your published files are quietly telling the world.

## Part 1 — The Tracking Audit Sheet

Run this on **every file you plan to publish.** One row per file. It takes about two minutes per item once you've done a few.

### How to score each layer

Score each layer **0, 1, or 2**:

- **0 = clean** (nothing found)
- **1 = something found, low risk** (e.g. generic software tag)
- **2 = something found, high risk** (e.g. identity-linking ID, provenance signature you didn't create, GPS)

Add the three layers for a **File Risk Score /6**.

### Interpreting the score

| Total | Verdict | What to do |
|-------|---------|------------|
| **0–1** | ✅ Publish now | Clean. Just add your seal. |
| **2–3** | ⚠️ Fix first | Strip metadata, re-export, then seal. |
| **4–6** | 🚫 Do not publish | Something is linking this file to a system or person. Rebuild from source. |

## Part 2 — Layer detail (tick what you find)

For each file, tick every item you actually discover. This is the evidence behind your score.

### Layer A — Metadata container
- [ ] `Make` / `Model` / device serial
- [ ] `Software` / `Producer` / editor version
- [ ] `Author` / `Creator` / `Artist` name
- [ ] `GPS` coordinates
- [ ] `UserComment` / free-text metadata
- [ ] XMP block present
- [ ] ID3 tags present (audio)
- [ ] QuickTime `com.apple` atoms (video)

### Layer B — Provenance signals
- [ ] C2PA / Content Credentials manifest present
- [ ] Manifest signed by a system **you did not use**
- [ ] SynthID-suspected output (Google model anywhere in the chain?)
- [ ] Model-supplier text mark suspected (Claude / Gemini / other, Aug 2026+)
- [ ] Cloud-tool signature present (Adobe / Canva / platform auto-tag)

### Layer C — Statistical signals
- [ ] Any paragraph generated by a model and *not* rewritten
- [ ] Uniform sentence rhythm on re-read
- [ ] Generic phrasing you wouldn't use out loud
- [ ] No lived detail (names, numbers, places, opinions)
- [ ] Output copy-pasted with zero human edit

## Part 3 — The Origin Log™

This is your **proof of authorship**. It is the single most valuable page in this system, because it is the thing you get to *show* when a buyer asks "is this really yours?"

Record one entry per published piece. Be specific. Be dated.

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
ORIGIN RECORD #____
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Title:            __________________________________

Type:             [ ] text  [ ] image  [ ] audio  [ ] video  [ ] mixed

Created (date):   __________________________________
Created (place):  __________________________________

Made by:          __________________________________
                  (your name — the human who made the calls)

Tools used:       __________________________________
                  __________________________________

Parts generated:  __________________________________
                  (be honest — "AI-assisted" is fine, undocumented is not)

Human work done:  __________________________________
                  (rewrites, direction, edits, shots — the real labor)

Stripped:         __________________________________
                  (what you removed and with what)

Sealed with:      __________________________________
                  (badge + disclosure block version)

Final file hash:  __________________________________
                  (optional: sha256 of the published file)

Signed:           __________________________________
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**Worked example (copy this level of detail):**

```
ORIGIN RECORD #014 — "Why I stopped letting AI write my intros"
Type: text (blog post, 1,400 words)
Created: 2026-09-18, Lisbon (home desk)
Made by: Ana R. (author; all structure, argument, and voice)
Tools used: Claude (research summary only), VS Code, Ulysses
Parts generated: opening brainstorm bullet list (2 lines) — discarded, not published
Human work done: full rewrite of every sentence in my own voice; added
                 3 personal stories, 2 client examples, my own opening line.
Stripped: exiftool -all= on all images; metadata containers emptied.
Sealed with: badge HP-◍ v2 + disclosure block v3
Final file hash: sha256 9f2c...a7 (published copy)
Signed: Ana R., 2026-09-18
```

Notice how honest it is. *That honesty is the asset.* A record that admits "AI-assisted for research" but proves "human-written for the parts that matter" is *more* credible than a claim of zero AI — because everyone can smell the difference.

## Part 4 — Monthly re-audit

The marks evolve. Set a recurring calendar entry for the **1st of every month** and do this:

1. Re-run this sheet on your **3 most-visited pieces**.
2. Check for any **new tool signature** you didn't have last month (did a platform start auto-tagging?).
3. Update your **disclosure block** if your tool stack changed.
4. Re-score your **Trust Score** (deliverable 6).

15 minutes a month keeps your proof current.

## Quick reference — command cheat sheet

```bash
# Read everything a file is saying about you
exiftool -a -G1 -s file.jpg

# Nuclear option: drop the entire metadata container (keeps image data)
exiftool -all= file.jpg

# Same for a PDF
exiftool -all= doc.pdf

# Check a file's hash for your origin log
sha256sum published-file.png
```
